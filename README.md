# 🤖 KAACRASH BOT

Bot WhatsApp modern berbasis **Baileys Original**.

## 👤 Creator
- **kaastr26**

## ✨ Fitur
- Login Pairing Code (Tanpa Scan QR)
- Anti Connection Closed
- Sistem Plugin

## 🚀 Cara Install
1. `npm install`
2. `npm start`
3. Ketik `1` di console, masukkan nomor WA.
4. Masukkan 8 digit Pairing Code ke WhatsApp.
